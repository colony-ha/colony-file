# COLONY FILE

COLONY FILE is a black-and-gold cloud storage product.

## Cloudflare Pages

This repository currently serves a static frontend from the `public` directory.

- Framework preset: **None**
- Build command: leave empty
- Build output directory: `public`
- Root directory: leave empty

The first commit creates the initial landing page. Authentication, file uploads, sharing, subscriptions, and the admin API will be added in later stages.

## Plans

- FREE: 1 GB
- PRO: 5 GB — $5/month
